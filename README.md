# Phố cổ Hội An — 발표 요약 페이지

**Xem trang:** https://tuong06.github.io/hoi-an/

`https://tuong06.github.io/hoi-an/` — 광운대학교 대학한국어(01) 발표 자료. HTML/CSS/JS thuần, không build step; GitHub Pages serve trực tiếp từ nhánh `main` / root.

- Nội dung tiếng Hàn + phiên âm Hangul, nút nghe phát âm (Web Speech API, vi-VN).
- Tranh minh họa SVG tự vẽ; Leaflet 1.9.4 và qrcode-generator vendor trong `assets/vendor/`.
- Tương tác: chế độ "Đêm phố cổ", dòng thời gian, sơ đồ nhà ống, xưởng lồng đèn + thả hoa đăng, thanh trượt mực nước lũ, đếm ngược đêm 14 âm lịch, quiz, bản đồ.
- Ngày thuyết trình ở bìa: 2026. 10. 02.

Xem local: `python3 -m http.server 8000` → http://localhost:8000
